# Pre-experiment engineering checks

Two real GPT-6 Sol High sessions were run before the frozen 30-run experiment.
Check 01 could not deliver MCP calls because the tool approval configuration was
missing. It produced no task answer. Check 02 used the corrected configuration,
read the v2 skill, made seven audited tool calls, and passed the decimal-invoices
verifier. These setup sessions are disclosed but excluded from the predeclared
30-run comparison. Their events and artifacts are preserved here. They are not
independent replications and must not be counted as extra task samples.
